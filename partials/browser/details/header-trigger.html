X-TalkDOM-Trigger

Response header · 0.5.0

Ask the browser to execute a talkDOM command after reading the response.

Example

X-TalkDOM-Trigger: notice text: Saved; feed get: /updates apply: inner
  • Enabled for readable responses by default, including cross-origin responses. Treat these servers as trusted command sources.
  • Set talkDOM.config.allowServerTriggers = false to disable.
  • Cross-origin servers must expose the header via Access-Control-Expose-Headers.
