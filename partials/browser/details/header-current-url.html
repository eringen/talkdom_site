X-TalkDOM-Current-URL

Request header · 0.5.0

Include the full current page URL for same-origin or explicitly trusted destinations.

Example

X-TalkDOM-Current-URL: https://example.com/page?view=1#section

// Omit this header entirely:
talkDOM.config.includeCurrentURL = false;
  • Includes query and fragment. Disabled for other origins by default.
  • Destination URLs resolve against the document base URI.
