talkDOM.send()

Programmatic API · 0.5.0

Dispatch the same message syntax used by sender attributes. Returns a promise for an array of independent chain results.

Example

await talkDOM.send("content get: /page.html apply: inner");
await talkDOM.send("notice text: Saved; feed get: /updates apply: inner");
  • Waits for every matching receiver before continuing a pipe, passing along the last receiver’s value.
  • A receiver failure rejects promptly, stops its pipe, and emits an error event; other already-started work continues.
  • Separate sends remain concurrent and may complete out of order. No automatic request cancellation.
  • Does not update history; use a sender with push-url for navigation.
