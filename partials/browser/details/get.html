get:

HTTP method · 0.5.0

Send a GET request. Pipe its response to another method to update the receiver.

Example

<div receiver="content"></div>
<button sender="content get: /api/data | content apply: inner">Load</button>
  • Returns a promise for the response text; failed requests reject and emit talkdom:error.
  • Sensitive headers go only to same-origin or explicitly trusted origins.
