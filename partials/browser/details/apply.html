apply:

DOM method · 0.5.0

Apply piped content to a receiver. Use text: for a direct literal text message.

Example

<button sender="content get: /page.html | content apply: inner">Load</button>

await talkDOM.deliver(element, "apply:", ["<b>Hello</b>", "inner"]);
  • inner replaces child HTML; text sets textContent; append adds HTML; outer replaces the element.
  • Invalid or denied operations emit talkdom:error and leave DOM/storage unchanged. Set talkDOM.config.strictApply = true to reject and stop pipes; legacy promises resolve by default.
  • HTML is not sanitized. Only apply trusted markup.
