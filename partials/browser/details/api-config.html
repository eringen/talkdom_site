talkDOM.config

Programmatic API · 0.5.0

Configure header trust, server triggers, and strict apply errors. Set startup configuration before the core script, or edit talkDOM.config later.

Example

window.talkDOMConfig = {
  trustedOrigins: ["https://api.example.com"],
  includeCurrentURL: false,
  allowServerTriggers: false,
  strictApply: true
};
  • Default values: empty trustedOrigins; includeCurrentURL/allowServerTriggers true; strictApply false.
  • Origins match exactly, including scheme and port. No wildcard trust.
  • Disabling server triggers prevents readable responses from executing command strings.
