X-CSRF-Token

Request header · 0.5.0

Send the page CSRF token on non-GET requests to same-origin or explicitly trusted destinations.

Example

<meta name="csrf-token" content="your-token">
<button sender="content post: /save apply: inner">Save</button>
  • Read from the csrf-token meta tag. Missing tokens warn for trusted non-GET requests.
  • Cross-origin destinations receive it only when their exact origin is explicitly trusted.
  • The server must still validate the token.
