text:

DOM method · 0.5.0

Set literal text without an HTTP request or pipe. Markup is displayed as text.

Example

<div receiver="notice"></div>
<button sender="notice text: Saved">Notify</button>
  • Respects accepts="text" and persistence.
  • Message delimiters still have meaning. Use talkDOM.deliver(element, "text:", [value]) for arbitrary literal strings.
