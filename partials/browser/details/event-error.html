talkdom:error

Lifecycle event · 0.5.0

Bubbling receiver event emitted when a delivered method fails.

Example

document.addEventListener("talkdom:error", function(event) {
  console.log(event.detail);
});
  • Detail includes receiver, selector, args, originalReceiver, error.
  • Shared by core sends, polling, and WebSocket applies.
  • Outer swaps dispatch from an actual inserted element; empty/text-only replacements fall back to the original parent or document.
