ws: (receive)

WebSocket plugin · 0.5.0

Subscribe a receiver to a WebSocket URL after loading the optional plugin.

Example

<script src="https://cdn.jsdelivr.net/npm/talkdom@0.5.0/dist/talkdom-ws.min.js"></script>
<div receiver="feed ws: wss://example.com/updates"></div>

// Server JSON:
{"receiver":"feed", "content":0, "op":"text"}
// Raw command:
feed text: Updated!
  • Load core before the plugin. Shared URLs share a connection.
  • receiver is optional; omission broadcasts to current subscribers of that connection. Named JSON also stays within that connection.
  • Content accepts strings, numbers, booleans, null/missing (empty). Invalid JSON/fields emit socket errors.
  • Raw commands have document-wide scope; connect only to trusted servers.
  • Attribute edits, removals, and inserted subscribers are reconciled automatically.
