talkDOM.receivers()

Programmatic API · 0.5.0

Return a fresh array of current elements matching a literal receiver name or alias.

Example

const elements = talkDOM.receivers("content");
for (const el of elements) await talkDOM.deliver(el, "text:", ["Hello"]);
  • Do not prefix a receiver name with # unless that character is part of the literal name.
  • The array includes same-turn DOM changes and can be safely modified by the caller.
