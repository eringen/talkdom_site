push-url

Attribute · 0.5.0

Update history only after the complete sender message succeeds. Back/Forward restores saved markup without replaying network or mutation commands.

Example

<a href="/about" sender="content get: /partials/about.html apply: inner" push-url="/about">About</a>
<main receiver="content">Home</main>
  • Empty values use the first message argument. URLs must resolve to the page origin.
  • Cancellation or a failed chain leaves the URL unchanged; successful independent chains may already have changed content.
  • Initial Back, Forward, and reload restore snapshots. Equivalent URLs do not create duplicate entries.
  • Snapshots replace receiver regions; use delegated listeners. Unsaved form properties and JavaScript state are not captured. Keep receiver layout consistent across reloads.
