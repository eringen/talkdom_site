get:apply:loading:

Custom example · 0.5.0

This is a site-registered example, not a built-in keyword in talkDOM 0.5.0. Register it before using the sender below.

Example

talkDOM.methods["get:apply:loading:"] = function(el, url, op, cls) {
  el.classList.add(cls);
  return talkDOM.methods["get:apply:"](el, url, op)
    .finally(function() { el.classList.remove(cls); });
};

// sender="content get: /data apply: inner loading: is-loading"
  • Load registration in a normal script, not inside a fetched HTML fragment.
  • This example wraps the built-in combined GET method and removes the class on success or failure.
