sender

Attribute · 0.5.0

Dispatch a message when this element, or a child, is clicked.

Example

<div receiver="content"></div>
<button sender="content get: /page.html apply: inner">Load</button>
  • Clicks are delegated from the document; fetched senders work without separate setup.
  • Pipes run sequentially; semicolon-separated chains start independently.
  • Sender clicks prevent the default action. Core does not add submit/change/input handling or form serialization.
