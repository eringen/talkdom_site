talkDOM.deliver()

Programmatic API · 0.5.0

Run a registered method on one element with structured arguments and normal lifecycle events.

Example

await talkDOM.deliver(element, "text:", ["Literal ; and | characters"]);
await talkDOM.deliver(element, "apply:", ["<b>Content</b>", "inner"]);
  • Returns a promise and preserves synchronous DOM updates for synchronous methods.
  • Useful for plugins and data that contains reserved message delimiters.
  • Outer-swap events target the first inserted element, or the original parent/document for text-only or empty replacements.
