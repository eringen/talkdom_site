Keyword Messages

Syntax · 0.5.0

Interleave receiver, keywords, and arguments. Keywords join to form the method selector.

Example

content get: /api/data apply: inner
// selector: get:apply:
// args: ["/api/data", "inner"]
  • Ordinary multiword arguments are rejoined.
  • | and ; split chains; whitespace tokens ending in : are keywords. Quotes/backslashes do not escape them.
  • Use structured talkDOM.deliver() arguments for arbitrary literal content.
