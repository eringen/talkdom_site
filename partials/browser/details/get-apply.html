get:apply:

Combined method · 0.5.0

Fetch content and apply it in one message. Interleave each keyword with its argument; get:apply: is the method-table selector.

Example

<button sender="content get: /api/data apply: inner">Load</button>

// Equivalent pipe
await talkDOM.send("content get: /api/data | content apply: inner");
  • Returns a promise for the response text; failed requests reject and emit talkdom:error.
  • Sensitive headers go only to same-origin or explicitly trusted origins.
  • Operations: inner, text, append, outer.
