accepts

Attribute · 0.5.0

Allow only the listed apply operations.

Example

<div receiver="notice" accepts="text inner"></div>

// Opt into rejecting denied or invalid applies:
talkDOM.config.strictApply = true;
  • Tokens are separated by whitespace, including tabs and newlines.
  • Missing or empty attributes allow all supported operations.
  • Denied/invalid operations emit an error event. Legacy promises resolve by default; strictApply stops downstream pipes.
