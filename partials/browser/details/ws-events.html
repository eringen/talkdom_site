WebSocket events

WebSocket plugin · 0.5.0

Receive connection and payload errors on connected subscribers.

Example

document.addEventListener("talkdom:ws:open", event => console.log(event.detail.url));
document.addEventListener("talkdom:ws:error", event => console.error(event.detail));
  • talkdom:ws:open: {url}; talkdom:ws:close: {url, code, reason}; talkdom:ws:error: {url, error?}.
  • Events bubble from subscribed receiver elements.
  • Apply errors also use the core talkdom:error lifecycle event.
