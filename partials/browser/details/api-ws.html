talkDOM.ws

WebSocket API · 0.5.0

Open, send through, and explicitly disconnect shared WebSocket connections.

Example

talkDOM.ws.connect("wss://example.com/live");
// After connections[url].state === WebSocket.OPEN:
talkDOM.ws.send("wss://example.com/live", {action:"subscribe"});
// When finished:
talkDOM.ws.disconnect("wss://example.com/live");
  • Manual ownership keeps a connection alive without DOM subscribers and enables reconnects.
  • disconnect closes the whole connection and cancels retries, including shared subscriptions.
  • send returns true if sent, false if not open. Object payloads are JSON-encoded.
  • connections exposes state and receiver count; maxConnections defaults to 16.
