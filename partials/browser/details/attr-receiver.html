receiver

Attribute · 0.5.0

Name an element as a message target. A message goes to every matching receiver.

Example

<div receiver="alert notice"></div>
<button sender="notice text: Hello">Notify</button>

<div receiver="feed get: /updates apply: inner poll: 5s"></div>
  • Names are literal, not CSS selectors. Names before the first keyword are aliases; tabs/newlines also separate tokens.
  • The first name is used for storage keys and the receiver request header.
  • Lookups see same-turn additions, removals, replacements, and name changes.
