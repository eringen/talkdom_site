ws:send:

WebSocket plugin · 0.5.0

Send an element value (or text content) over an already open socket.

Example

<input receiver="chat ws: wss://example.com/chat">
<button sender="chat ws:send: wss://example.com/chat">Send</button>
  • Wait for talkdom:ws:open before enabling Send.
  • Returns a rejected promise if no open connection exists.
